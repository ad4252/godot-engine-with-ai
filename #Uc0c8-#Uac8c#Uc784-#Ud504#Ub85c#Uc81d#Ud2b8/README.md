# The Dicebound Chronicle — Godot 프로젝트

Godot 4.7 프로젝트입니다.

## 실행
1. Godot 4.7에서 `project.godot`를 엽니다.
2. 메인 씬을 실행합니다.
3. 공격 속성과 강화 효과를 선택하고 주사위 굴리기를 누릅니다.

## 변경 사항
- TRPG/다크 판타지 스타일의 전투 HUD 재구성
- HP 게이지, 내성 배분, AI 상태, 전투 로그를 한 화면에 정리
- 내성 SpinBox를 명시적 노드 이름으로 연결
- 내성 포인트 총합 3점 제한 유지
- EnemyAI의 선택 주사위 범위를 실제 적 전투 주사위에 반영
- 최근 최대 8회의 플레이어 전투 행동을 AI에 전달
- AI 요청 실패 시 EnemyAI의 기본 주사위 전략으로 전투 지속

## Gemini API
`GEMINI_API_KEY` 환경 변수를 설정하면 EnemyAI가 Gemini API를 요청합니다. 키를 프로젝트 파일이나 저장소에 직접 입력하지 마세요. 환경 변수가 없거나 API 요청에 실패하면 기본 주사위 범위로 진행합니다.

## 게임 규칙 참고
- 양측은 주사위 2개를 굴리고 합계가 높은 쪽이 승리합니다.
- 합계 차이만큼 기본 피해를 줍니다.
- 플레이어 내성: 0=취약(2배), 1=보통(1배), 2=내성(0.2배). 총합 3점 제한.
- 강화: 주사위+1 또는 고정+5 피해.

※ 실제 실행/에디터 검증은 Godot 4.7에서 최종 확인해야 합니다.
